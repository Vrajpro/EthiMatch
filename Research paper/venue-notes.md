# Venue notes

Pick the venue **before** heavy drafting — it fixes page limit, template, and anonymity rules.

## Candidate venues

| Venue | Fit | Format | Notes |
|-------|-----|--------|-------|
| **AMIA Informatics Summit / AMIA Annual Symposium** | High — clinical informatics audience, values reproducibility | 5-page submission (Summit) or 10-page (Annual) | Non-anonymous. Strong fit for the audit-UI contribution. |
| **ACL / EMNLP Clinical NLP Workshop (ClinicalNLP)** | High — biomedical NER + evaluation | 8 pages + refs, ACL template | Anonymous. Would need to foreground the NER + negation handling angle. |
| **MLHC (Machine Learning for Healthcare)** | Medium — expects stronger validation than synthetic data alone | 12 pages | Reviewers typically push back on synthetic-only evaluation. Only pursue if MIMIC results strengthen. |
| **JAMIA Open (short report)** | Medium–high — accepts prototype / tooling papers | ~3,000 words | Good fallback for a tooling-paper framing. |
| **arXiv (preprint)** | Always | Any | Post before or alongside any venue submission. |

## Recommendation

Start by writing to a **generic 8-page two-column IMRaD template** (see `outline.md`). This can be reflowed into AMIA Summit (trim to 5 pages) or ClinicalNLP (ACL template, 8 pages + unlimited refs) without rewriting the content.

## Anonymisation checklist (if targeting ClinicalNLP / anonymous venue)

- [ ] Remove author name, student number, supervisor name from the paper
- [ ] Replace "Coventry University" / "MSc 7005SCN" with "a UK Master's project" (or similar)
- [ ] Rename the public GitHub repo link to an anonymised mirror for review
- [ ] Scrub acknowledgements until camera-ready
