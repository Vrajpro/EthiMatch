# Data used in EthiMatch

I used two open datasets for this project. Both sit in this folder so an examiner can see what the prototype actually reads.

## Synthea (`data/synthea/`)

Synthetic patients generated by Synthea (Walonoski et al., 2018). There is no real-patient privacy restriction.

**Files in this repository (needed for the demo):**

- `patients.csv`
- `conditions.csv`
- `medications.csv`
- `careplans.csv`
- `encounters.csv`
- plus smaller supporting tables (`procedures.csv`, `immunizations.csv`, `allergies.csv`, and similar)

**Not on GitHub (file-size limits):**

| File | Approx. size | Why it is missing |
|------|----------------|-------------------|
| `claims_transactions.csv` | 296 MB | Over GitHub’s 100 MB limit |
| `observations.csv` | 88 MB | Too large to publish reliably |
| `imaging_studies.csv` | 50 MB | Large and not required to run matching |
| `claims.csv` | 40 MB | Not required to run matching |

If `observations.csv` is present locally, the loader can fill cancer stage from it. Without that file, the rest of the pipeline still runs.

## MIMIC-IV Demo (`data/mimic/`)

Public MIMIC-IV Demo subset (Johnson et al., 2023): 100 de-identified patients, no PhysioNet credential.

Included tables: `patients`, `admissions`, `diagnoses_icd`, `d_icd_diagnoses`, `d_icd_procedures`, `prescriptions`.

I did not include credentialed MIMIC-IV-Note free text. That was out of scope for this MSc project.
